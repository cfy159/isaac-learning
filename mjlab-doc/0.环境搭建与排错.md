# 安装 mjlab 基础环境

> 对应 isaac-learning 笔记第 0 篇的定位（环境先行、先排坑再谈训练）。**本篇的安装对象是 mjlab 框架本体**——luwu_mjlab 只是我们后续的参考项目（它在 mjlab 之上扩展了陆吾机器人），不是本篇的安装对象。

## 0. mjlab 是什么

三句话：

- mjlab = **Isaac Lab 的 manager-based API + MuJoCo Warp**（GPU 加速版 MuJoCo），轻量、PyTorch 原生。
- 训练**必须 NVIDIA GPU**（macOS 只能做评估）；Python 要求 **3.10 ~ 3.13**。
- 装好后得到一组命令行工具：`train` / `play` / `list_envs` / `demo` / `export-scene` / `viz-nan`。

| 包 | 版本关系 | 说明 |
|---|---|---|
| mjlab | 本体 | RL 环境框架（Isaac Lab 风格 API） |
| mujoco / mujoco-warp | mjlab 的依赖 | 物理引擎 + GPU 加速 |
| warp-lang | mjlab 的依赖 | **1.2.0 这一代要求 ≥1.12 且 <1.14**（依赖 `wp.context.runtime`，1.14 起被移除） |
| torch、rsl-rl、tensorboard 等 | mjlab 的依赖 | 训练栈 |

## 1. 方式一：零安装试跑（官方推荐先体验）

先装 [uv](https://docs.astral.sh/uv/)（Python 包管理器）：

```powershell
# Windows PowerShell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

```bash
# Linux / macOS
curl -LsSf https://astral.sh/uv/install.sh | sh
```

然后一行命令跑官方 demo（自动拉取 mjlab，不污染任何环境）：

```bash
uvx --from mjlab --refresh demo
```

## 2. 方式二：源码安装（官方 Getting Started）

```bash
git clone https://github.com/mujocolab/mjlab.git && cd mjlab
uv run demo
```

之后所有命令都通过 `uv run` 前缀执行：

```bash
uv run train Mjlab-Velocity-Flat-Unitree-G1 --env.scene.num-envs 4096
```

> 第 1 篇按官方 [create_new_task.ipynb](https://github.com/mujocolab/mjlab/blob/main/notebooks/create_new_task.ipynb) 教程创建新任务时，用的就是这份源码——但采用 **editable 安装**（`pip install -e .`）：新任务要放进 `src/mjlab/tasks/` 源码树里才能被官方 `train/play` 发现，editable 让改动即时生效。详见第 1 篇第 1 节。

## 3. 方式三：PyPI 安装进自己的环境

```bash
conda create -n mjlab python=3.11
conda activate mjlab
pip install mjlab
```

> mjlab 在 PyPI 上提供 `cpu` / `cu128` 两种 extras（对应不同 CUDA 版本的 torch）；GPU 训练需确保 torch 是 CUDA 版。完整说明见官方 [Installation Guide](https://mujocolab.github.io/mjlab/main/source/installation.html)。

## 4. 验证安装

```bash
# ① 列出官方内置任务（pip 安装直接用命令；源码安装加 uv run 前缀）
list_envs

# ② MDP 冒烟测试：零动作策略，不需要任何训练好的模型
play Mjlab-Velocity-Flat-Unitree-Go1 --agent zero

# ③ 正式训练一次（Go1 四足，平地速度跟踪）
train Mjlab-Velocity-Flat-Unitree-Go1 --env.scene.num-envs 4096
```

官方内置任务（mjlab 1.2.0，本地验证）：

| 任务 ID | 说明 |
|---|---|
| `Mjlab-Velocity-Flat-Unitree-Go1` | Go1 四足 · 平地速度跟踪 |
| `Mjlab-Velocity-Rough-Unitree-Go1` | Go1 四足 · 崎岖地形 + 地形课程 |
| `Mjlab-Velocity-Flat-Unitree-G1` | G1 人形 · 平地速度跟踪 |
| `Mjlab-Velocity-Rough-Unitree-G1` | G1 人形 · 崎岖地形 |

（另有 tracking 动作模仿、manipulation 操作任务族，`list_envs` 可全部列出。）

viewer 说明：有显示环境弹原生 MuJoCo 窗口；无显示/Windows 自动切 viser 网页版，浏览器访问 `http://localhost:8080`。

## 5. 与参考项目 luwu_mjlab 的关系

本系列后续以 [luwu_mjlab](https://github.com/LuwuDynamics/luwu_mjlab) 为参考实现讲解，它是「基于 mjlab 做扩展」的活例子：

- luwu_mjlab 的 `setup.py` 锁定 `mjlab==1.2.0`、`warp-lang==1.12.1`，安装它时会**自动把 mjlab 作为依赖装好**。
- 所以如果你已经装过 luwu_mjlab（比如本机的 `D:\anaconda3\envs\luwu_mjlab` 环境），**可以跳过本篇安装，直接验证**：

```bash
conda activate luwu_mjlab
python -c "import mjlab; print(mjlab.__version__)"   # 应输出 1.2.0
```

- 版本建议：跟参考项目对照学习就用 1.2.0；单独尝鲜可装最新版（API 可能有差异）。

## 6. 常见报错排查

思路和 isaac 笔记第 0 篇一致：**报错先看「库加载/版本问题」，再看「环境变量/PATH 问题」，最后才是代码问题。**

| 现象 | 原因 | 解法 |
|---|---|---|
| warp 初始化失败 / `wp.context.runtime` 缺失 | warp-lang ≥ 1.14 | `pip install "warp-lang>=1.12,<1.14"`（1.2.0 这一代） |
| `torch.cuda.is_available()` 为 False | 驱动低 / torch 是 CPU 版 | 升级驱动；重装 CUDA 版 torch |
| `uv: command not found` | uv 没装或不在 PATH | 按第 1 节安装 uv，或重开终端 |
| Linux 无显示环境崩在渲染 | EGL/显示后端 | 训练是 headless 的，检查 `MUJOCO_GL`；看可视化用 viser 网页版 |
| Windows 下 DLL 加载失败 | conda 的 `Library\bin` 不在 PATH 前面 | 把 `%CONDA_PREFIX%\Library\bin` 放到 PATH 最前 |
| `nvcc` 版本不对 | CUDA toolkit 未装对 | 按官方 Installation Guide 对齐 torch 的 CUDA 版本 |

- `list_envs` 能列出 `Mjlab-Velocity-Flat-Unitree-Go1` 等任务
- `play Mjlab-Velocity-Flat-Unitree-Go1 --agent zero` 不报错、viewer 里 Go1 站在平地上
